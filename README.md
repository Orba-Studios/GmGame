# GmGame

GmGame is a lightweight, simple desktop game launcher and library manager built with Python. It allows you to organize your local games or application shortcuts and launch them cleanly from a single user interface.

## Features
- Add local game executables or files to your library.
- Launch games instantly with a single click.
- Clean graphical user interface.

1. Install Python on your system.
2. Install PyInstaller via terminal:
